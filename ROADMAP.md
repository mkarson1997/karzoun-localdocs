# Roadmap

## v0.1 local catalog
- recursive local indexing
- streaming SHA-256 fingerprints
- duplicate grouping
- stable path identity
- local tags and metadata search
- versioned atomic JSON persistence
- restart reconstruction
- symlink boundary protection

## Privacy hardening
- authenticated encrypted metadata vault
- corruption/tamper detection
- key-provider abstraction
- Apple Keychain adapter

## Apple integration
- sandbox/security-scoped URL adapter
- incremental filesystem change handling
- Finder/SwiftUI host example where useful

## Release
- reproducible source archive
- checksums
- provenance where useful
- versioned release notes
